# 💎 Welcome to Ruby Adventure! 

## Your Journey to Becoming a Ruby Developer Starts Here! 🚀

### How to Play:
1. **Start with Level 1** - Each level builds essential Ruby skills
2. **Read the README.md** for concepts and examples
3. **Edit script.rb** to complete the challenges
4. **Run bash check.sh** to test your code
5. **Move to the next level** when you pass!

### What You'll Learn:
- 💎 Level 1: Ruby Basics & Variables
- ⚙️ Level 2: Methods & Control Flow
- 🗂️ Level 3: Data Structures
- 📁 Level 4: File Handling & Classes
- 🔮 Level 5: Advanced Ruby & Metaprogramming
- 🏆 Final: Complete Task Manager Project

### Getting Started:
```bash
cd game/ruby/level1
cat README.md          # Read instructions and examples
nano script.rb         # Write your Ruby code
bash check.sh          # Test your solution
```

### Running Your Code:
```bash
ruby script.rb         # Run your Ruby code directly
ruby test.rb          # Run the automated tests
```

### Why Ruby?
- 🎯 **Beautiful syntax** - Designed for developer happiness
- 💼 **Versatile** - Web development, scripting, automation
- 🚀 **Productive** - Express complex ideas with less code
- 🛠️ **Great ecosystem** - Ruby on Rails, Sinatra, and more
- 👥 **Friendly community** - Helpful and welcoming
