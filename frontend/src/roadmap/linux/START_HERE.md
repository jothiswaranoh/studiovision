# 🐧 Welcome to Linux Adventure! 

## Your Journey to Becoming a Linux Expert Starts Here! 🚀

### How to Play:
1. **Start with Level 1** - Each level builds essential Linux skills
2. **Read the README.md** for concepts and examples  
3. **Follow challenge.sh** for guided tasks
4. **Run bash check.sh** to test your skills
5. **Move to the next level** when you're comfortable!

### Learning Path:
- 🗂️ Level 1: Basics & Navigation
- 📄 Level 2: File Operations
- 📝 Level 3: Text Processing
- 🔒 Level 4: Permissions & Processes
- 🐚 Level 5: Shell Scripting
- 🏆 Final: Real Projects

### Getting Started:
```bash
cd linux/level1
cat README.md          # Read instructions
bash challenge.sh      # See challenges
bash check.sh          # Test your skills
```

### Game Structure:
- Each level has its own directory
- README.md explains concepts
- challenge.sh provides tasks
- test.sh validates your learning
- check.sh runs the tests

**Ready to master Linux? Begin with Level 1! 💪**

> 💡 **Tip**: Practice regularly and don't be afraid to experiment in a safe environment!
