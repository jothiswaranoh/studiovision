# 🎯 Level 1: Making Things Pretty! 🎨

**Your Mission:** Add colors and basic styling to your HTML page.

**What You'll Learn:**
- How to connect CSS to HTML
- Changing text colors
- Changing background colors
- Basic selectors (targeting elements)

**Three Ways to Add CSS:**
1. **Inline** (in HTML tag): `<p style="color: red;">`
2. **Internal** (in HTML head): `<style> p { color: red; } </style>`
3. **External** (separate file): `<link rel="stylesheet" href="style.css">`

**Challenge:**
Make your heading blue and add a light gray background to the page.

**Example:**
```css
/* Make all h1 elements blue */
h1 {
  color: blue;
}

/* Make page background light gray */
body {
  background-color: lightgray;
}
```

**🎨 Color Options:**
- Named: `red`, `blue`, `green`, `purple`, `orange`
- Light: `lightblue`, `lightgray`, `lightgreen`  
- Dark: `darkblue`, `darkred`, `darkgreen`

**Run `bash check.sh` when you're ready to see your colorful creation!**
