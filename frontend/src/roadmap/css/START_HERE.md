# 🎨 Welcome to CSS Adventure! 

## Your Journey to Beautiful Websites Starts Here! ✨

### How to Play:
1. **Start with Level 1** - Each level builds CSS knowledge
2. **Read the README.md** for instructions and examples
3. **Edit style.css or index.html** to complete challenges
4. **Run bash check.sh** to verify your work
5. **Move to the next level** when you pass!

### What You'll Learn:
- 🎨 Level 1: Colors & Basic Styling
- 🔤 Level 2: Fonts & Text Styling  
- 📦 Level 3: Box Model & Spacing
- 📐 Level 4: Flexbox Layouts
- 📱 Level 5: Responsive Design & Grid
- 🏆 Final: Complete Portfolio Design

### Getting Started:
```bash
cd game/css/level1
cat README.md          # Read instructions
nano index.html        # Edit HTML with CSS
# or nano style.css    # Edit CSS file
bash check.sh          # Check your work
```

### View Your Styled Pages:
After adding CSS, refresh your HTML file in a web browser to see the changes!

**Ready to make the web beautiful? Start with Level 1! 🚀**

> 💡 **Tip**: Experiment! Try different colors and values to see what looks best.
