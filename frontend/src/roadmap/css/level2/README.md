# 🎯 Level 2: Beautiful Text & Fonts ✨

**Your Mission:** Make your text stylish with fonts, sizes, and spacing.

**What You'll Learn:**
- Changing font families
- Adjusting font sizes
- Text alignment and decoration
- Font weights (boldness)

**Common Properties:**
```css
p {
    font-family: Arial, sans-serif;  /* Font type */
    font-size: 16px;                 /* Text size */
    text-align: center;              /* Alignment */
    font-weight: bold;               /* Bold text */
    text-decoration: underline;      /* Underline */
    line-height: 1.5;                /* Line spacing */
}
```

**Challenge:**
- Make headings use Arial font
- Center align your main heading
- Make paragraphs larger (18px+)
- Add some bold text

**📝 Font Size Units:**
- `px` - pixels (16px)
- `em` - relative to parent (1.5em)
- `rem` - relative to root (1.2rem)
- `%` - percentage (120%)

**🔤 Font Families:**
- `Arial, sans-serif` - Clean modern
- `"Times New Roman", serif` - Classic
- `"Courier New", monospace` - Typewriter style

**Run `bash check.sh` to see if your text looks fabulous!**
