# 🏆 Final Challenge: Build Your Portfolio! 🌟

**Your Mission:** Combine everything you've learned to create a personal webpage!

**This is your chance to show off all your new HTML skills!**

**Requirements:**
✅ Use semantic structure (header, nav, main, footer)  
✅ Include at least one image with alt text  
✅ Add a navigation bar with links  
✅ Create a contact form  
✅ Include either a list OR table  
✅ Write proper page title and description

**Page Sections Idea:**
1. **Header** - Your name and title
2. **Navigation** - Links to Home, About, Contact
3. **Main Content** - About you section
4. **Image** - Your photo or avatar
5. **Skills** - Table or list of your skills
6. **Contact Form** - For visitors to message you
7. **Footer** - Copyright and social links

**Example Structure:**
```html
<!DOCTYPE html>
<html>
<head>
  <title>My Portfolio</title>
  <meta name="description" content="A beginner web developer's portfolio">
</head>
<body>
  <header>...</header>
  <nav>...</nav>
  <main>
    <section>...</section>
    <img src="..." alt="...">
    <table>...</table>
    <form>...</form>
  </main>
  <footer>...</footer>
</body>
</html>
```

**🎉 You've got this!** You've learned all the building blocks - now combine them creatively!

**Run `bash check.sh` when your masterpiece is complete!**
