# 🎯 Level 5: Organizing Information 📊

**Your Mission:** Create a table showing top programming languages.

**What You'll Learn:**
- Creating tables to show data
- Making lists (bulleted and numbered)

**New Tags:**
**For Tables:**
- `<table>` - Creates a table
- `<tr>` - Table row
- `<th>` - Table header
- `<td>` - Table data cell

**For Lists:**
- `<ul>` - Unordered list (bullets)
- `<ol>` - Ordered list (numbers)
- `<li>` - List item

**Challenge:**
Create a table of "Top 3 Programming Languages" with:
- Language Name
- Popularity
- Use Case

**Example Table:**
```html
<table>
  <tr>
    <th>Language</th>
    <th>Popularity</th>
    <th>Use</th>
  </tr>
  <tr>
    <td>JavaScript</td>
    <td>#1</td>
    <td>Web Development</td>
  </tr>
  <!-- Add more rows -->
</table>
```

**💡 Tip:** Tables are great for data, lists are great for items!

**Run `bash check.sh` to see if your data is well-organized!**
