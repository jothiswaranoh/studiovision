# 🎮 Welcome to HTML Adventure! 

## Your Journey to Becoming a Web Developer Starts Here! 🌐

### How to Play:
1. **Start with Level 1** - Each level builds on the previous one
2. **Read the README.md** in each level for instructions
3. **Edit the index.html** file to complete the challenge
4. **Run bash check.sh** to see if you passed
5. **Move to the next level** when you succeed!

### Getting Started:
```bash
cd game/html/level1
cat README.md          # Read instructions
nano index.html        # Edit the HTML file
bash check.sh          # Check your work
```

### What You'll Learn:
- 🎯 Level 1: Basic HTML & Headings
- 🏗️  Level 2: Page Structure & Semantics  
- 🖼️  Level 3: Links & Images
- 📝 Level 4: Forms & User Input
- 📊 Level 5: Tables & Lists
- 🏆 Final: Combine Everything!

### Tools You Need:
- Any text editor (VS Code, Notepad, Nano, etc.)
- A web browser to view your pages
- Terminal/Bash to run checks

### View Your Webpages:
After editing HTML, open the file in a web browser to see your creation!

**Ready? Start with Level 1! The world wide web awaits! 🌍**

> 💡 **Tip**: Don't rush! Understand each concept before moving to the next level.
