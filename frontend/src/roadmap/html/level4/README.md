# 🎯 Level 4: Interactive Forms! 📝

**Your Mission:** Create a login form with email and password fields.

**What You'll Learn:**
- Creating forms with `<form>`
- Different input types with `<input>`
- Labels with `<label>`
- Buttons with `<button>`

**New Tags:**
- `<form>` - Container for form elements
- `<input type="text">` - Text input field
- `<input type="password">` - Password field (hidden text)
- `<label>` - Description for input fields
- `<button>` - Clickable button

**Challenge:**
Create a login form with:
- Email field
- Password field  
- Submit button

**Example:**
```html
<form>
  <label>Email:</label>
  <input type="email" placeholder="Enter your email">
  
  <label>Password:</label>
  <input type="password" placeholder="Enter your password">
  
  <button type="submit">Login</button>
</form>
```

**💡 Pro Tips:**
- Use `type="email"` for email validation
- Use `placeholder` to show example text
- `type="password"` hides what users type

**🔒 Note:** This form won't actually send data yet - we're learning the HTML structure!

**Run `bash check.sh` when your form is ready!**
