# 🎯 Level 1: Your First Web Page

**Your Mission:** Create a simple webpage that says "Welcome to the Web Solver!"

**What You'll Learn:**
- Basic HTML structure
- How to create headings
- How to write paragraphs

**Steps:**
1. Open `index.html` in a text editor
2. Inside the `<body>` section, add this code:
   ```html
   <h1>Welcome to the Web Solver!</h1>
   <p>I'm learning HTML!</p>
   ```
3. Save the file
4. Run the check: `bash check.sh`

**💡 Tip:** `<h1>` is for main headings, `<p>` is for paragraphs.

**Ready? Let's build your first webpage! 🚀**
