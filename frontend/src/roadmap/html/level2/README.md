# 🎯 Level 2: Building a House for Your Content 🏗️

**Your Mission:** Build a webpage with proper structure using HTML5 tags.

**What You'll Learn:**
- Semantic HTML (tags that describe their purpose)
- Organizing content logically

**New Tags:**
- `<header>` - Top section of your page
- `<nav>` - Navigation menu
- `<main>` - Main content area  
- `<section>` - A section of content
- `<footer>` - Bottom section

**Challenge:**
Create a page that uses ALL 5 tags above.

**Example Structure:**
```html
<header>Page Header</header>
<nav>Navigation Links</nav>
<main>
  <section>Content Section 1</section>
  <section>Content Section 2</section>
</main>
<footer>Page Footer</footer>
```

**💡 Tip:** Semantic tags help screen readers and search engines understand your page!
