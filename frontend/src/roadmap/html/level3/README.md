# 🎯 Level 3: Making Connections & Adding Pictures 🖼️

**Your Mission:** Add a clickable link and display an image.

**What You'll Learn:**
- Creating hyperlinks with `<a>` tags
- Adding images with `<img>` tags

**New Tags:**
- `<a href="url">Link Text</a>` - Creates a clickable link
- `<img src="image.jpg" alt="description">` - Displays an image

**Challenge:**
Add at least one link and one image to your page.

**Examples:**
```html
<!-- Link to Google -->
<a href="https://www.google.com">Visit Google</a>

<!-- Image from the web -->
<img src="https://placekitten.com/200/300" alt="Cute kitten">

<!-- Local image (if you have one) -->
<img src="myphoto.jpg" alt="My photo">
```

**💡 Important:**
- Always add `alt` text to images for accessibility
- Links need `href`, images need `src` and `alt`

**🌐 Pro Tip:** You can use free image URLs like:
- `https://placekitten.com/200/300` (cute cats!)
- `https://picsum.photos/200/300` (random images)

**Ready? Run `bash check.sh` to check your links and images!**
