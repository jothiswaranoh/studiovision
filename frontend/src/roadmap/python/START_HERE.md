1. **Start with Level 1** - Each level builds essential Python skills

### Getting Started:
```bash
cd game/python/level1
cat README.md          # Read instructions and examples
nano script.py         # Write your Python code
bash check.sh          # Test your solution
```

### Running Your Code:
```bash
python3 script.py      # Run your Python code directly
python3 test.py       # Run the automated tests
```
