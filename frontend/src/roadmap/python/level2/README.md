# 🎯 Level 2: Functions & Control Flow ⚙️

**Your Mission:** Learn to create functions and make decisions in your code.

**What You'll Learn:**
- Defining and calling functions
- If/else statements
- For and while loops
- Function parameters and return values

**Functions (Reusable Code Blocks):**
```python
# Function definition
def greet(name):
    return f"Hello, {name}!"

# Function call
message = greet("Alice")
print(message)  # "Hello, Alice!"
```

**Conditional Statements:**
```python
age = 18

if age >= 18:
    print("You can vote!")
elif age >= 16:
    print("You can drive!")
else:
    print("You're too young.")
```

**Loops:**
```python
# For loop (iterate through sequences)
fruits = ["apple", "banana", "orange"]
for fruit in fruits:
    print(fruit)

# While loop (repeat while condition is true)
count = 0
while count < 5:
    print(count)
    count += 1
```

**Comparison Operators:**
- `==` Equal to
- `!=` Not equal to
- `>` Greater than
- `<` Less than
- `>=` Greater than or equal to
- `<=` Less than or equal to
