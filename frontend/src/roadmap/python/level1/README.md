# 🎯 Level 1: Python Basics & Variables 🐍

**Your Mission:** Learn Python fundamentals - variables, data types, and basic operations.

**What You'll Learn:**
- Python syntax and indentation
- Variables and data types
- Basic operations and input/output
- String manipulation

**Why Python is Awesome:**
- Clean, readable syntax
- No semicolons or curly braces
- Uses indentation for code blocks
- Great for beginners and pros alike

**Variables & Data Types:**
```python
# Strings (text)
name = "Alice"
message = 'Hello World'

# Numbers
age = 25
height = 5.9
is_student = True

# Lists (arrays)
fruits = ["apple", "banana", "orange"]
numbers = [1, 2, 3, 4, 5]
```

**Basic Operations:**
```python
# Math operations
sum = 5 + 3       # 8
difference = 10 - 4 # 6
product = 3 * 4    # 12
quotient = 15 / 3  # 5.0

# String operations
greeting = "Hello" + " " + "World"  # "Hello World"
name_length = len("Alice")          # 5
```

**Input/Output:**
```python
# Getting user input
name = input("What's your name? ")

# Displaying output
print("Hello, " + name)
print(f"Hello, {name}!")  # f-string (modern way)
```
